# 이야기의 문법

소설과 웹소설의 플롯·인물·장면·시점·정보 설계를 움직이는 다이어그램으로 한 단계씩 배우는 무료 인터랙티브 강의입니다.

- 8개 장, 22개 레슨: 이야기의 엔진 · 인물 · 구조 · 장면과 완급 · 시점과 서술 · 정보 설계 · 세계와 관계 · 장편과 연재
- 자매 사이트: [화면의 문법](https://yeongbin-jo.github.io/screen-grammar/) (웹 디자인·모션, 영상 촬영·편집)

## 로컬에서 보기

빌드 과정이 없는 정적 사이트입니다.

```sh
python3 -m http.server 4181
# http://localhost:4181/
```
